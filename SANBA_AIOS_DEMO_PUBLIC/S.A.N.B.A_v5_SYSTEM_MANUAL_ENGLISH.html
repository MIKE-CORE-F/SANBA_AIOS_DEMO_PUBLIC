1. System Architecture & Sovereign IP

S.A.N.B.A. AI-OS v5.0 combines a high-performance Python Single-Kernel foundation with an optional, distributed Erlang OTP Actor mesh (AGENTS/MCL_BRIDGE/). In this public baseline most components are demo stubs; the Erlang sources are included but are not started by the demo scripts. The demo runs locally and makes no cloud calls.

Core Architecture: The Python kernel manages agent logic, context injection, and local execution, while the Erlang OTP actor layer handles optional state governance, network broadcasting, and P2P node communication.

  • Local Footprint: The demo runs locally on host hardware (Linux / WSL) and makes no cloud calls.
  • Governance: The financial governor applies amount limits (allow / revise / block). The groundlaws engine and drift watchdog are stubs and verify nothing yet; commands are checked against an allowlist.
  • Optional Mesh / Station Mode: Placeholder for P2P clustering. The included mesh demo is a local two-node TCP example without authentication.

2. Official Boot Scripts (WSL / Linux)

Navigate to the project root directory in your Linux / WSL terminal:

cd /path/to/SANBA_AIOS_DEMO_PUBLIC

Execute the universal boot.sh script to launch the desired operating mode:

#!/bin/bash
# ==================================================================
# S.A.N.B.A. AI-OS v5.0 - Universal Boot Script
# ==================================================================

echo "=================================================================="
echo " 🚀 S.A.N.B.A. AI-OS v5.0 - STARTING LOCAL DEMO BASELINE"
echo "=================================================================="

if ! command -v python3 &> /dev/null
then
    echo "[ERROR] Python3 could not be found."
    exit 1
fi

if [ "$1" == "--with-mesh" ]; then
    echo "[MESH] Activating optional local network node (Station mode)..."
    python3 DEMO_MULTI_NODE_MESH.py
else
    echo "[INFO] Running the local demo boot (no cloud calls, components are stubs)."
    python3 AIOS_BOOT.py
fi

echo "=================================================================="
echo " ✨ System operational and ready for demonstration!"
echo "=================================================================="

3. Command Center & CLI Cheatsheet

Use these commands in your terminal during the demonstration to drive individual layers and simulations:

System Layer / Function Terminal Command Description / Demo Action
System Boot (Pure Local) ./boot.sh or python3 AIOS_BOOT.py Loads the demo components and reports which ones loaded (most are stubs).
Multi-Node Mesh (Station) ./boot.sh --with-mesh or python3 DEMO_MULTI_NODE_MESH.py Runs a local two-node TCP demo (the Erlang bridge is not started).
Smoke tests python3 test_smoke.py Runs 10 checks of the command guard, orchestrator, financial governor and snapshots.
VPU Mesh Status python3 -m CORE.VPU_MESH.MESH_ROUTER Displays active load balancing across VPU threads.
Agent Cockpit python3 -m AGENTS.COCKPIT.AGENT_COCKPIT Opens the interactive interface for task assignment.
